# Lumora-AI

Lumora AI es una inteligencia artificial de código disponible que busca ser un asistente eficiente para la creación de código totalmente gratuito e ilimitado.

Usa WebGPU y funciona sin necesidad de conexión a Internet, se divide en 4 modelos llamados 'Pro-coder'.

# ¿Que puedes hacer como usuario?

• Como usuario eres libre de usar la IA como quieras, actualmente esta en una etapa Alpha por lo que no puedes esperar a que todo sea como quieres, el modelo pro-coder es un modelo recién salido y aun esta en entrenamiento agresivo para enseñar todos los conceptos y ejemplos de programación y ciberseguridad.

• Si logras enseñarle algo valioso a nuestra IA o la IA dice algo que no debería por favor comunícate con el desarrollador desde GitHub y guarda el archivo .JSON de entrenamiento, si eres de teléfono te pediré que saques una captura, cada reporte nos ayuda a mejorar nuestra inteligencia.
